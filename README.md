# 🥗 Drika Personal Chef - Pratos Congelados Saudáveis

Plataforma oficial de apresentação e pedidos da **Drika Personal Chef**, especializada em refeições saudáveis, nutritivas e congeladas para facilitar o dia a dia com sabor de comida caseira de verdade.

---

## ✨ Funcionalidades

- **Cardápios Oficiais**:
  - **Linha Low Carb**: 9 opções exclusivas de pratos com teor reduzido de carboidratos.
  - **Linha Tradicional & Fit**: 9 opções balanceadas para o cotidiano.
- **Painel Administrativo da Chef**:
  - Ativação / desativação de pratos conforme disponibilidade de insumos da semana.
  - Gestão de pedidos e controle rápido de status.
- **Carrinho e Checkout Integrado**:
  - Adição rápida de itens com controle de quantidade.
  - Cálculo automático com cupom e taxa de entrega.
  - Pagamento facilitado via **Pix Copia e Cola / QR Code**.
  - Finalização direta via **WhatsApp** com resumo estruturado do pedido.
- **Identidade Visual Personalizada**:
  - Logo oficial e apresentação da trajetória da chef.
  - Totalmente responsivo para celulares e desktops.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** & **CSS3** (Tailwind CSS via CDN + Estilos personalizados)
- **JavaScript Moderno (ES6+)**
- **Lucide Icons**
- **Armazenamento Local (LocalStorage)** para persistência do estado e cardápio dinâmico

---

## 🚀 Como Executar Localmente

Basta clonar o repositório e abrir o arquivo `index.html` em qualquer navegador:

```bash
git clone https://github.com/cleitonalexandrino/drika-personal-chef.git
cd drika-personal-chef
# Abra index.html no seu navegador preferido
```
